# FedSOC-Guard

Détection fédérée, robuste et calibrée d'anomalies sur logs par Transformer
auto-supervisé, avec contextualisation des alertes par RAG MITRE ATT&CK.

## Problématique
Les organisations ne peuvent pas partager leurs logs, disposent de peu de
labels, et les analystes SOC sont submergés d'alertes.

## Thèmes intégrés
- T1 : Transformers
- T3 : RAG
- T8 : Self-Supervised Learning
- T9 : Explainable & Reliable AI
- T10 : Federated Learning
- T11 : Adversarial ML

## Datasets
- Loghub : https://github.com/logpai/loghub
- MITRE ATT&CK : https://attack.mitre.org/
